# Site Amanda Pego

Este projeto está preparado para publicação no GitHub Pages.

## Publicar
1. Crie um repositório no GitHub.
2. Envie **o conteúdo desta pasta** para a raiz do repositório (não envie a pasta ZIP inteira).
3. No repositório, acesse **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/(root)`, depois clique em **Save**.
6. Aguarde a publicação. O GitHub exibirá o endereço do site na seção Pages.

A página inicial é `index.html`. Os artigos e a pasta `assets` devem permanecer na raiz, mantendo a estrutura atual.
